# 🪙 Coin Collector Game

A 2D coin-collecting game built with **HTML, CSS, and vanilla JavaScript**. Explore the island as Luffy, collect coins, and try to increase your score!

## 🎮 How to Play

1. Press **Start** on the welcome screen after Luffy greets you.
2. Use the **arrow keys** to move Luffy around the island.
3. Walk into a coin to collect it. A new coin will appear somewhere else.
4. Earn **1 point** for every coin collected.
5. Stay within the island boundaries.
6. Use the 🔊 button in the corner to mute or unmute the music.

## ✨ Features

- 🏝️ Interactive island environment
- 👒 Animated player character
- 🪙 Spinning coins and random coin placement
- 🏆 Real-time score counter
- 🔊 Coin collection sound effects and background music
- 🎵 Mute/unmute button
- 💬 Welcome screen featuring Luffy's dialogue

## 🚀 Run It Locally

**1. Clone the repository**

```bash
git clone https://github.com/ALIMN9/coin-collector-game.git
```

**2. Open the project folder**

Open the cloned folder in VS Code.

**3. Launch the game**

Open the `StartingMenu` HTML file using the Live Server extension in VS Code, or open the HTML file directly in your browser.
