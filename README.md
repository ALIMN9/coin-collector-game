# Coin Collector Game

A 2D coin-collecting game built with vanilla HTML, CSS, and JavaScript.

## 🎮 How to Play

- Use the **arrow keys** to move Luffy around the island
- Luffy can't walk off the island

## 🛠️ Tech Stack

- HTML
- CSS
- JavaScript
